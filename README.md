# Node.js Application Deployment on AWS EC2

A fully deployed Node.js web application running on an AWS EC2 Ubuntu cloud instance, secured with Nginx as a reverse proxy and Let's Encrypt SSL (HTTPS).

## 🚀 Live Demo
* **Website:** [https://ishtiaq-app.duckdns.org](https://ishtiaq-app.duckdns.org)

## 🛠️ Tech Stack & Tools
* **Backend:** Node.js, Express
* **Cloud Infrastructure:** AWS EC2 (Ubuntu Linux)
* **Web Server / Reverse Proxy:** Nginx
* **Security & SSL:** Let's Encrypt, Certbot (HTTPS)
* **Domain & DNS:** DuckDNS
* **Version Control:** Git & GitHub
